# Qoder CLI 本地会话

<!-- release-target: both -->

## 新增功能

- 在设置中开启 Qoder 可选来源后，除 Qoder IDE 的会话外，现在也会索引在终端里使用 Qoder CLI 产生的本地会话，可搜索、筛选、按项目查看，并阅读用户与助手消息、工具调用记录以及所在的 Git 分支。
- Qoder CLI 会话优先展示其自动生成的标题，在列表中更容易辨认。
- 仅包含工具执行记录、没有实际对话内容的轨迹不再作为会话出现，避免无标题的空条目干扰搜索结果。
- 终端里的 Qoder CLI 会话现在单独归为「Qoder CLI」来源，可以直接用 Resume 回到原来的对话（在会话所属目录下执行 `qoder --resume`），也支持复制 Resume 命令和在 iTerm 中恢复。
- Qoder IDE 的会话现在可以通过「Open App」唤起 Qoder 桌面端，不再直接报错。

## Bug 修复

- 修复「Open App」按钮出现在没有桌面端的来源上、点击后必然报错的问题：现在只有确实能唤起桌面应用的会话才会显示该按钮。
